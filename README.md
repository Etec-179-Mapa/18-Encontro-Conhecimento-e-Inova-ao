# 18º Encontro — mapa da feira

Só HTML, CSS e JavaScript. Não tem banco, não tem servidor e não precisa instalar nada.

Dê dois cliques em `index.html` para abrir no navegador.

Para publicar no GitHub Pages, coloque estes arquivos na raiz do repositório, na branch `main`:

- `index.html` — a página
- `css/style.css` — o visual
- `js/app.js` — a busca, os pisos e os 47 projetos
- `assets/mapas/` — os três desenhos oficiais da planta
- `assets/icone.svg` — o ícone da aba

O site fica em https://rezende-hk.github.io/Mapa-18-Encontro-ETEC/
